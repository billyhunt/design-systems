Lisa

Ink does the talking. The rainbow does the shouting. Shadows by day, glow by night.

Lisa is a neon, 90s-school-supplies design system with two modes, Day and Dusk. Every value on this page comes from one set of tokens, the same ones in lisa.css. Flip the mode switch and only the tokens change. The rulebook explains why; tokens.json has the same values for design tools.

Principles

Six rules. When in doubt, these win.

1

Neon is a fill.

By Day it never carries text. By Dusk it may, because every fill passes 4.5:1 on Midnight.

2

Ink does the talking.

One text colour, one muted, one accent for links. That is all the coloured text there is.

3

Every edge is 3px.

Borders, rules, outlines and shapes. It keeps the neon from melting together, and it keeps working when colour drops out.

4

Shadows by day, glow by night.

Depth is the one token that changes shape between modes. Everything else only swaps colour.

5

Tilt one thing per view.

A sticker, a badge, a burst. Two tilted things and the page looks dropped.

6

One job per shape.

Two buttons, two toggles, a badge, an avatar, a tile and one unicorn. Shapes never swap jobs.

Components

Real controls. Hover, press, Tab through them, click the toggles.

Buttons · cloud pill for most actions, plain pill for dense UI, unicorn once

States. Hover brightens the fill. Pressed drops --depth and shifts --press (3px). Focus draws a --ring that follows the outline. Disabled goes dashed and muted, with no depth.

Cloud pills are fixed sizes in v0.1. Long or translated labels use the plain pill until the cloud can stretch.

Prose

Plain HTML inside .lisa-prose. Links are --accent-text; code is a dark well.

Keep the loud stuff in its lane

Colour carries state, never meaning on its own. Read the principles before adding a seventh neon, and highlight one phrase per block at most.

  • Spectrum slabs top and bottom only
  • One neon fill per component
  • One tilt per view
The rainbow is the border. Ink does the talking.
.button {
  background: var(--fill-1);
  color: var(--on-fill);
  border: var(--rule) solid var(--border);
  border-radius: var(--radius-pill);
  box-shadow: var(--depth-sm);
}

Use it

Four files. Link the stylesheet and the fonts, add class="lisa", and opt components in.

FileWhat it is
index.htmlThis page. Every token and component, live, in both modes.
README.mdThe rules and why they exist. Read it before designing anything new.
lisa.cssDrop-in stylesheet: tokens for Day and Dusk, .lisa-* components, prose, print. Inert until an element opts in.
tokens.jsonThe same tokens in the Design Tokens Community Group format, for design tools.

Mark & print

The wordmark, the icon, and what survives paper.

Lisa

The unicorn icon holds at 64px and up. At 32px it turns into a blob, so the favicon uses the sparkle.

Print

Always prints in Day. White ground; glows and the airbrush sky drop out. Fills stay under ink. The spectrum slab prints as a solid ink bar, and every shape keeps its 3px outline, so nothing depends on colour.
